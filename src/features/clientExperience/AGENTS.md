# Клиентский опыт

- Каноническая методология: `docs/CLIENT_EXPERIENCE.md`; UI: `docs/DESIGN_SYSTEM.md`.
- Поток: импорт → нормализация → темы → тональность совпадений → серверные агрегаты → UI.
- Не меняйте формулы тональности, CXI, Problem Index и версии моделей без отдельной задачи, тестов и обновления вкладки «Методология».
- Не загружайте все отзывы во frontend; используйте RPC, диапазоны и пагинацию.
- Черновик не влияет на рабочие показатели до полного успешного перерасчёта и атомарной публикации.
- Проверки: `npm run test:cx`, затем `npm run lint` и `npm run build`.
