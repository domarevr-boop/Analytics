# Данные и импорт

- Контракты: `docs/IMPORTS.md`, профильный документ источника и `PROJECT_STATE.md`.
- Поток: файл → source detection/mapping → валидация → нормализованные сущности → repository/store → аналитика.
- Не меняйте source-field ownership, даты, финансовые формулы или ключи слияния без явной задачи и проверки реального файла.
- Частично распознанный источник обновляет только присутствующие поля и не обнуляет связанные метрики.
- Большие наборы не должны обходить диапазонные выборки, серверные агрегаты или пагинацию.
- Проверки: `npm run lint`, `npm run build`; для CX также `npm run test:cx`.
