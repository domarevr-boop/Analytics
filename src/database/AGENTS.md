# Хранилище и Supabase

- Основные отчёты остаются local-first; серверный CX-контур описан в `docs/CLIENT_EXPERIENCE.md`.
- Не ломайте идемпотентность, порядок пагинации, RLS, приватность, миграционную совместимость и атомарную публикацию версий.
- SQL/RPC должен агрегировать и фильтровать данные на сервере; не возвращайте полный массив отзывов.
- Миграция должна быть самодостаточной для своего контракта и безопасной при последовательном применении.
- Секреты и `.env.local` не редактируются и не коммитятся.
- Проверки: целевой SQL/RPC сценарий, затем `npm run test:cx`, `npm run lint`, `npm run build`.
