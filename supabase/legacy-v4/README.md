# Legacy V4/CX Supabase reference

Эти файлы сохранены только для аудита и будущего контролируемого переноса CX. Они происходят из production-контура V4 и **не входят** в активную цепочку миграций V5.

Запрещено копировать каталог обратно в `supabase/migrations/` целиком или применять его к проекту V5 без отдельного аудита зависимостей, данных и RLS. Нужные механизмы переносятся отдельными V5-миграциями с контрольными данными.
