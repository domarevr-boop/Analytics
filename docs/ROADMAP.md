# Roadmap Analytics MVP

Проверено: **14 сентября 2026**. Production — **V4**, отдельный staging — **V5**.

Прогресс по текущему проверяемому пулу V5: **57 из 69 пунктов (83%)**. Это процент выполнения расширенного migration-roadmap, а не готовность к production: после технического переноса «Поисковых запросов» декомпозирован контур «Воронка/реклама», где аудит выявил блокирующую ошибку семантики заказов XWay.

Roadmap содержит только незавершённую работу. Принятые результаты фиксируются в version-документах; этапы, зависимости, проверки и откат V5 описаны в [V5_MIGRATION_PLAN](V5_MIGRATION_PLAN.md).

## V5 — полный перенос страниц на сервер

Основной приоритет после готовых серверных каркасов «Географии» и «Точек входа»: принять их реальные партии и страницы → завершить browser-приёмку «Конкурентов» → «Поисковые запросы» → «Воронка/реклама» → «Рентабельность» → CX hardening → «Планирование» → «Главная»/товар → «Отчётность». Каждая страница проходит один и тот же gate: источник и lineage → разрешение/создание связанных сущностей → серверное хранение/RPC → frontend без локального fallback → функциональная browser-приёмка. Финансовые блоки возвращаются после переноса денежных источников, а не через смешивание V4/V5; общая ролевая приёмка выполняется последним этапом.
