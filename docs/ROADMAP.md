# Roadmap Analytics MVP

Проверено: **11 сентября 2026**. Production — **V4**, отдельный staging — **V5**.

Прогресс по текущему проверяемому пулу V5: **46 из 52 пунктов (88%)**. Это процент выполнения зафиксированного migration-roadmap, а не готовность к production: две аналитические страницы подключены к серверным read-контрактам за выключенными release-флагами, а неразмеченный будущий backlog в расчёт не входит.

Roadmap содержит только незавершённую работу. Принятые результаты фиксируются в version-документах; этапы, зависимости, проверки и откат V5 описаны в [V5_MIGRATION_PLAN](V5_MIGRATION_PLAN.md).

## V5 — полный перенос страниц на сервер

Основной приоритет после готового серверного каркаса «Географии»: импорт-управляемые товары + «География» → «Конкуренты» → CX hardening → «Точки входа» → «Поисковые запросы» → «Воронка/реклама» → «Рентабельность» → «Планирование» → «Главная»/товар → «Отчётность». Каждая страница проходит один и тот же gate: источник и lineage → разрешение/создание связанных сущностей → серверное хранение/RPC → frontend без локального fallback → функциональная browser-приёмка. Финансовые блоки «Географии» возвращаются после переноса денежных источников, а не через смешивание V4/V5.
