# Roadmap Analytics MVP

Обновлено: **10 августа 2026**. Активная версия — **v4.0**.

## Текущий фокус: клиентский опыт

### Выполнено

- [x] Отзывы изолированы в Supabase; остальные источники остаются local-first.
- [x] Импорт WB поддерживает пакетную запись, дедупликацию, сверку строк и удаление временного файла.
- [x] Реализованы таксономия и словарь правил `exact_keyword`, `lemma`, `lemma_phrase`, `context`.
- [x] Реализованы нормализация, поиск тем, аспектная тональность и версионирование моделей.
- [x] Реализованы безопасная публикация словаря, возобновляемый полный перерасчёт и перерасчёт диапазона.
- [x] Реализованы обзор, список отзывов, рабочее пространство тем, методология и настройки анализа.
- [x] Добавлены Overall/Product/Service/Outcome CXI, вклад тем, сравнение равных периодов и Problem Index.
- [x] Добавлены серверные агрегаты, пагинация, гранулярность День/Неделя/Месяц и KPI-спарклайны.
- [x] Карта тем приведена к симметричной матрице `Нишевые / Мейнстрим × Позитивные / Негативные`.
- [x] Начальная загрузка ограничена последним месяцем с данными.

### Следующие задачи

- [ ] Провести контрольную ручную валидацию словаря на размеченной выборке и зафиксировать precision/recall по основным темам.
- [ ] Добавить мониторинг качества: доля классифицированных отзывов, доля оценочных совпадений, неизвестные формулировки и изменения после публикации словаря.
- [ ] Добавить экспорт таблицы тем и выбранной детализации без выгрузки полного массива отзывов во frontend.
- [ ] Проверить доступность, пустые состояния и адаптивность всех вкладок CX после финальной стабилизации словаря.

## Правила ведения roadmap

- Roadmap содержит только незавершённые задачи и краткий список результатов текущего крупного этапа.
- Завершённые исторические работы переносятся в документ версии.
- Изменение формулы, архитектуры хранения или общего UI-паттерна обновляет соответствующий канонический документ в том же коммите.
