# Документация Analytics MVP

Обновлено: **30 августа 2026**.

Это единственная актуальная карта документации. Соседние Git worktree и внешний каталог `_archive` не являются источниками текущих правил.

## С чего начинать

1. [README](../README.md) — назначение проекта, запуск и публикация.
2. [PROJECT_STATE](../PROJECT_STATE.md) — фактическая архитектура, рабочие разделы и ограничения.
3. [ROADMAP](ROADMAP.md) — только незавершённые задачи в порядке приоритета.
4. [VERSIONS](VERSIONS.md) — активная и запланированная версии.
5. Корневой и ближайший локальный `AGENTS.md` — обязательные правила изменения кода.
