# Версии Analytics MVP

**Актуальная версия: [v4.0](versions/v4.0.md)**.

| Версия | Статус | Описание |
|---|---|---|
| [v0.1](versions/v0.1.md) | Архив | Базовый MVP. |
| [v2.0](versions/v2.0.md) | Архив | Периоды, вычисляемые из данных. |
| [v3.0](versions/v3.0.md) | Завершена | Стабильный рабочий контур: импорт, планы, рентабельность, справочник, изображения и Dashboard. |
| [v4.0](versions/v4.0.md) | **В работе** | Плановые ДРР и рекламный бюджет, затем новые аналитические страницы. |
| [v6.0](versions/v6.0.md) | Запланирована | Следующая продуктовая версия с отдельным URL и развитием экономики аналитических страниц. |

План актуальной версии находится в [ROADMAP.md](ROADMAP.md).

## Правило URL версий

- При переходе к новой основной версии создаётся отдельный URL вида `/Analytics/vX/`.
- Предыдущая принятая версия остаётся доступной по своему адресу и не перезаписывается новой сборкой.
- Для v6 зарезервирован адрес `/Analytics/v6/`; публикация выполняется только при фактическом начале версии.
