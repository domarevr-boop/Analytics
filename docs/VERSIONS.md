# Версии Analytics MVP

**Актуальная версия: [v4.0](versions/v4.0.md).**

| Версия | Статус | Результат |
|---|---|---|
| [v0.1](archive/history/versions/v0.1.md) | Архив | Базовый MVP и первичный импорт. |
| [v2.0](archive/history/versions/v2.0.md) | Архив | Периоды и вычисления из фактических дат. |
| [v3.0](archive/history/versions/v3.0.md) | Архив | Стабильный локальный рабочий контур: импорт, планы, финансы, справочник, изображения и Dashboard. |
| [v4.0](versions/v4.0.md) | **В работе** | Расширенная аналитика, единая дизайн-система и серверный контур клиентского опыта. |
| [v6.0](versions/v6.0.md) | Запланирована | Отдельный URL, экономика точек входа и задачи масштабирования. |

Активные задачи находятся только в [ROADMAP.md](ROADMAP.md). Исторические детали хранятся в version-документах и не дублируются в roadmap.

Исторические version-документы находятся в `docs/archive/history/versions/` и не являются требованиями к текущей версии.

## Правило URL

- Новая принятая версия получает отдельный адрес `/Analytics/vX/`.
- Предыдущая принятая версия сохраняется доступной и не перезаписывается новой сборкой.
- Для v6 зарезервирован `/Analytics/v6/`; публикация выполняется при фактическом старте версии.
