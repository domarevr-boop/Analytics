# Версии Analytics MVP

Проверено: **6 сентября 2026**.

**Production: [v4.0](versions/v4.0.md). Активная разработка: [v5.0](versions/v5.0.md).**

| Версия | Статус | Результат |
|---|---|---|
| [v0.1](archive/history/versions/v0.1.md) | Архив | Базовый MVP и первичный импорт. |
| [v2.0](archive/history/versions/v2.0.md) | Архив | Периоды и вычисления из фактических дат. |

| [v5.0](versions/v5.0.md) | **Подготовка backend** | Централизованные данные, серверный импорт и воспроизводимые расчёты в отдельном контуре. |

Активные задачи находятся только в [ROADMAP](ROADMAP.md), подробный переход — в [V5_MIGRATION_PLAN](V5_MIGRATION_PLAN.md). Исторические документы не являются требованиями.

## Правило изоляции и URL

- V4 остаётся на `main` и рабочем URL до отдельного принятия V5.
- V5 разрабатывается в `v5/backend-foundation`, отдельном worktree и отдельном Supabase-проекте.
- Ветка V5 не публикуется текущим workflow. Зарезервированный `/Analytics/v5/` появится только через составной deployment, сохраняющий V4.
- Архивирование V4 возможно только после выполнения release gates V5 и явного решения владельца.
