# Поисковые запросы WB

## Импорт

- Источник: `Поисковые запросы WB`.
- Обязательные поля: дата, поисковый запрос, количество запросов, предмет, переходы в карточку, корзины и заказы.
- Формат даты `ДД.ММ` поддерживается через выбор года в предпросмотре импорта.
- Записи сохраняются отдельно от товарных метрик по ключу `дата + нормализованный запрос + предмет`.
- Повторный импорт той же строки обновляет запись и не создаёт дубль.

## Аналитическая панель

- Общие KPI спроса и конверсий.
- Сравнение текущего и предыдущего периода для всей категории.
- Динамика отдельного поискового запроса.
- Карта спроса и конкуренции: товары по оси X, запросы по Y, заказы задают размер точки.
- Рейтинги растущих запросов и возможностей.
- Агрегированная сортируемая таблица с пагинацией по 50 строк.

## Производительность

Исходные строки не выводятся целиком. Страница агрегирует текущую выборку и рендерит ограниченные рейтинги, до 250 точек карты и 50 строк таблицы. Для объёма в сотни тысяч строк это снижает нагрузку интерфейса, но дальнейший рост до нескольких месяцев полного отчёта потребует серверной агрегации или отдельного аналитического движка.

## Расчёты

- `CR корзины = добавления в корзину / переходы в карточку`.
- `CR заказа = заказы / добавления в корзину`.
- `Сумма заказов по ключу = заказали товаров × средний чек предмета из отчёта «Динамика ниши» за тот же месяц`.
- Запрос сопоставляется с нишей через поле `Больше всего заказов в предмете` → `Предмет`.
- Для текущего периода используется текущий средний чек ниши, для предыдущего периода — средний чек из соответствующей предыдущей колонки.
- Если предмет или месяц не найдены в динамике ниши, сумма заказов остаётся нулевой; интерфейс показывает процент сопоставленных строк.
- Рост спроса считается относительно одноимённой колонки предыдущего периода.
- Индекс возможности — сравнительный, а не финансовый показатель: высокий спрос и невысокая конверсия повышают оценку, высокая конкуренция снижает её.
