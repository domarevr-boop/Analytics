# География заказов

## Импорт

- Обязательные поля: `Дата`, `Артикул продавца`, `Регион`, `Итого заказов, шт`, локальные и не локальные заказы по товарам.
- Уникальный ключ: `date + product_id + region + area + city`; повторный импорт обновляет только совпадающий географический срез.
- Иерархия хранится как `ФО → область → населённый пункт`. Если для товара, даты и ФО появились детальные строки, старые агрегаты без области или города исключаются, чтобы не задваивать показатели.
- Нижняя таблица показывает только реальные области и входящие в них населённые пункты. Для старых отчётов без колонок `Область` и `Город` выводится честное сообщение об отсутствии детализации.
- СВД принимает `0д 23ч`, `2д 4ч` или число часов. Значение `-` исключается из среднего и отражается через покрытие данных.
- Если в файле есть WB ID, название, бренд и предмет, они обновляют справочник товара.

## Расчёты

- Локальность = локальные заказы по товарам / все заказы.
- Среднее время доставки — взвешенное по количеству заказов, только по строкам с известным СВД.
- Потенциал локализации = минимум из не локальных заказов и доступного остатка WB + МП. Это ориентир, а не рекомендация о фактическом перемещении запасов.
- Цели локальности и СВД хранятся отдельно для каждого месяца.
