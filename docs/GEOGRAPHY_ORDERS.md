# География заказов

## Импорт

- Обязательные поля: `Дата`, `Артикул продавца`, `Регион` или `Кластер`, `Итого заказов, шт`.
- `Регион`/`Кластер` хранится в поле `region` и используется как верхний уровень иерархии; `Область` и `Город` — дополнительные уровни детализации.
- Уникальный ключ: `date + product_id + region + area + city`; повторный импорт обновляет только совпадающий географический срез.
- Если для товара, даты и кластера появились детальные строки, старые агрегаты без области или города исключаются, чтобы не задваивать показатели.
- СВД принимает `0д 23ч`, `2д 4ч` или число часов. Значение `-` исключается из среднего и отражается через покрытие данных.
- Поля локальных/нелокальных заказов сохраняются только для совместимости со старыми файлами и не участвуют в текущем интерфейсе.
- Если в файле есть WB ID, название, бренд и предмет, они обновляют справочник товара.

## Расчёты

- Заказы — сумма `orders_total` по строкам выбранного среза.
- Доля заказов территории = заказы территории ÷ заказы базового товарного среза × 100.
- Среднее время доставки — взвешенное по количеству заказов, только по строкам с известным СВД; покрытие СВД = заказы строк с СВД ÷ все заказы × 100.
- Сумма заказов и чистая прибыль распределяются по географии пропорционально заказам внутри сочетания `дата + товар`; это расчётная атрибуция, а не исходные финансовые поля географического отчёта.
- Средний чек = расчётная сумма заказов ÷ количество заказов. Изменения KPI сравниваются с непосредственно предшествующим периодом равной длины.

## Карта и рейтинги

- Карта строится по реальным областям из текущего фильтрованного среза и использует SVG-геометрию `@react-map/russia` (MIT).
- Доступны четыре режима: `Сумма заказов`, `СВД`, `Доля ЧП`, `Доля суммы заказов`.
- Доля ЧП = чистая прибыль области ÷ сумма чистой прибыли показанных областей. При нулевом знаменателе значение отсутствует; отрицательные значения получают отдельную красную шкалу.
- Доля суммы заказов = сумма заказов области ÷ сумма заказов показанных областей.
- В блоке рейтингов выбор кластера ограничивает два соседних Top-5: регионы и населённые пункты. Их сумма заказов показывается в млн ₽ (`5 000 000` → `5`, `300 000` → `0,3`), а доля — от суммы выбранного среза; остаток объединяется в `Остальные`.
- СВД окрашивается по обратной шкале: меньшее время считается лучшим. Территории без геометрии остаются доступны в таблицах.
