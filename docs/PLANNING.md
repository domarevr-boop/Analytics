# Планирование

Обновлено: **1 сентября 2026**.

## Назначение

Страница хранит утверждённый совокупный план и независимую сценарную модель по месяцам выбранного года. Импорт Excel не используется: каждый кабинет показан отдельной компактной таблицей, значения вводятся на уровне категории. Итоги кабинета и ВБ всегда рассчитываются из категорий. Бренды и товары без назначенной категории на странице не показываются.

## Расчёт

В интерфейсе редактируются только сумма заказов по месяцу и рентабельность категории. Если для старой записи прямой суммы нет, она продолжает рассчитываться из сохранённых количества и среднего чека; после ручного ввода прямая сумма становится месячной целью. Выкупы и перечисление рассчитываются из суммы заказов и сохранённых ставок, чистая прибыль — из суммы выкупов и рентабельности. Родительские проценты и средний чек считаются взвешенно, денежные и количественные показатели суммируются. Пустое значение остаётся неизвестным (`—`), а не превращается в ноль.

Для текущего года по умолчанию видны текущий и будущие месяцы. Кнопка над таблицами временно возвращает прошедшие месяцы. Категория раскрывает дневные расчёты и число дней; сворачивание не меняет данные.

## Источник плана

Глобальный переключатель «Совокупный план — источник истины» действует на все месяцы. Пока он выключен, главная использует прежний поартикульный план. После включения главная и её плановые колонки используют только утверждённый совокупный план; отсутствующий месяц не подменяется старыми значениями. Сценарная модель никогда не влияет на главную и может копироваться из утверждённого плана или сбрасываться отдельно за выбранный год.

## Хранение и проверки

Данные local-first хранятся в IndexedDB `aggregate_monthly_plans`, настройка источника — в `planning_settings`. Схема IndexedDB — 11. Основные проверки: `npm run test:planning`, `npm run build`, lint затронутых файлов. При изменении формул, иерархии или подключения к главной этот документ обновляется в том же коммите.
