# Планирование

Обновлено: **1 сентября 2026**.

## Назначение

Страница хранит утверждённый совокупный план и независимую сценарную модель по месяцам выбранного года. Импорт Excel не используется: каждый кабинет показан отдельной компактной таблицей, значения вводятся на уровне категории. Итоги кабинета и ВБ всегда рассчитываются из категорий. Бренды и товары без назначенной категории на странице не показываются.

## Расчёт

В утверждённом плане сумма заказов, процент выкупа, процент к перечислению и рентабельность задаются отдельно для каждого месяца: общая сумма и ставки не распределяются автоматически. Ставки доступны в раскрытии категории. Если для старой записи прямой суммы нет, она продолжает рассчитываться из сохранённых количества и среднего чека; после ручного ввода прямая сумма становится месячной целью. Выкупы и перечисление рассчитываются из суммы заказов и сохранённых ставок, чистая прибыль — из суммы выкупов и рентабельности. Родительские проценты и средний чек считаются взвешенно, денежные и количественные показатели суммируются. Пустое значение остаётся неизвестным (`—`), а не превращается в ноль.

Введённые ставки сохраняются как независимые поля одной месячной записи: изменение процента выкупа, процента к перечислению или рентабельности не очищает соседние значения. Каждый ввод применяется поверх последнего состояния локального хранилища, после чего зависимые суммы пересчитываются. При неполном наборе ставок отсутствующие суммы не восстанавливаются предположением: для суммы выкупов и чистой прибыли должен присутствовать плановый процент выкупа.

Для текущего года по умолчанию видны текущий и будущие месяцы. Кнопка над таблицами временно возвращает прошедшие месяцы. Категория раскрывает дневные расчёты и число дней; сворачивание не меняет данные.

## Источник плана

Глобальный переключатель «Совокупный план — источник истины» действует на все месяцы. Пока он выключен, главная использует прежний поартикульный план. После включения главная и её плановые колонки используют только утверждённый совокупный план; отсутствующий месяц не подменяется старыми значениями.

Сценарная модель хранится отдельно и по каждому месяцу редактирует сумму заказов, средний чек, процент выкупа, процент к перечислению и рентабельность. Таблица показывает план, сценарий и отклонение; остальные показатели рассчитываются. «Применить сценарий» после подтверждения заменяет утверждённый план выбранного года, предварительно сохранив его резервную копию. Последнее применение можно отменить; планы других лет не изменяются.

Настройки столбцов управляют только расчётными колонками и сохраняются в браузере. По умолчанию остаются ключевые сумма заказов, сумма выкупов, рентабельность и чистая прибыль; остальные показатели включаются по необходимости. Категория, сумма заказов, рентабельность и месячная ось остаются обязательными. Кабинеты можно сворачивать независимо в утверждённом плане и сценарии.

## Хранение и проверки

Данные local-first хранятся в IndexedDB `aggregate_monthly_plans`, настройка источника — в `planning_settings`. Схема IndexedDB — 11. Основные проверки: `npm run test:planning`, `npm run build`, lint затронутых файлов. При изменении формул, иерархии или подключения к главной этот документ обновляется в том же коммите.
