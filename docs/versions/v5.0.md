# Analytics MVP v5.0

Проверено: **20 сентября 2026**. Статус: **staging, 65 из 69 пунктов текущего roadmap (94%)**. Server-only «Конкуренты», «Точки входа», «Поисковые запросы», «География» и «Воронка/реклама» приняты в браузере на постоянных dev-партиях; production остаётся V4.

## Цель

V5 переносит источники, историю импорта, нормализованное хранение и расчёты основных отчётов в отдельный Supabase/PostgreSQL-контур. Страница переносится только законченным сценарием `источник → загрузка → хранение → расчёт → UI`; перенос формулы не совмещается с изменением методологии.

## Следующая граница

Следующая граница — завершить серверный перенос «Рентабельности», чтобы восстановить финансовые связи без локального fallback. Исторический bootstrap не блокирует страницы; доказанный backup/restore остаётся release-gate надёжности, а ручная ролевая приёмка выполняется единым финальным проходом.
