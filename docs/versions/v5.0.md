# Analytics MVP v5.0

Проверено: **6 сентября 2026**. Статус: **подготовка изолированного backend-фундамента**. Зарезервированный URL `/Analytics/v5/` пока не опубликован.

## Цель

V5 переносит источники, историю импорта, нормализованное хранение и расчёты основных отчётов в отдельный Supabase/PostgreSQL-контур. Страница переносится только законченным сценарием `источник → загрузка → хранение → расчёт → UI`; перенос формулы не совмещается с изменением методологии.

## Следующая граница

Нужен отдельный Supabase-проект V5. После его создания выполняется только этап 1: чистый backend-фундамент, роли, private Storage и контракт партий импорта. Массовый перенос страниц, API-автоматизация, редизайн, публикация и архивирование V4 в эту границу не входят.
