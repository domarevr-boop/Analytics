# Analytics MVP v5.0

Проверено: **7 сентября 2026**. Статус: **пилот первого источника до ручной UI-приёмки**. Зарезервированный URL `/Analytics/v5/` пока не опубликован.

## Цель

V5 переносит источники, историю импорта, нормализованное хранение и расчёты основных отчётов в отдельный Supabase/PostgreSQL-контур. Страница переносится только законченным сценарием `источник → загрузка → хранение → расчёт → UI`; перенос формулы не совмещается с изменением методологии.

## Выполнено

- V5 создана от production commit `8dd7db8` в ветке `v5/backend-foundation` и отдельном worktree `C:\Users\vipdo\Documents\test\Analytics-v5`.
- V4 в `main` сохранена без изменений; текущий deployment не публикует V5.
- Из V5 удалены унаследованная Supabase CLI-привязка и устаревший дублирующий SQL-файл; env-шаблон не содержит рабочего проекта.
- Проведён аудит local-first data layer, импорта, CloudRepository, CX/Supabase, Auth/RLS, deployment, документации и агентских средств.
- Подготовлены [реестр](../INDEX.md) и [план миграции](../V5_MIGRATION_PLAN.md) с этапами, проверками, откатом и release gates.
- Создан отдельный Supabase-проект V5; URL, publishable key и отличие от V4 проверены без публикации секретов.
- Историческая V4/CX-цепочка исключена из активных миграций. Чистый foundation, private Storage/RLS-контракты и автоматический guard применены к V5; журнал миграций, db lint, health RPC и anon-изоляция проверены.
- Первый admin назначен; роли admin/viewer/importer и кабинетная изоляция проверены транзакционно без сохранения fixtures.
- Для источника «Рынок» реализованы версионные дневные факты, сохранение lineage, серверная валидация, атомарная публикация, безопасный повторный импорт, отмена партии и bounded RPC день/неделя/месяц. Функциональный smoke прошёл и полностью откатил тестовые данные.
- Import UI для «Рынка» использует отдельный Web Worker с `read-excel-file`, сохраняет исходник в private Storage и показывает сводку партии. Реальный V4-файл из 95 строк транзакционно сверен с parser V4 и серверными агрегатами V5; расхождений нет, данные откачены.
- Страница «Рынок» подключена к ограниченным RPC за V5-only feature flag. В этом режиме она не читает локальный рынок и явно показывает ошибку Supabase; остальные потребители источника пока не переключены.

## Следующая граница

Следующая граница — ручная UI-приёмка импорта и серверного отображения «Рынка», затем явное решение о переносе downstream «Поисковые запросы»/«Отчётность». Реальные разные viewer/importer и доказанное backup/restore остаются release gates. Массовый перенос страниц, API-автоматизация, редизайн, публикация и архивирование V4 пока не входят.
