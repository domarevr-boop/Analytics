## Замороженный backlog — поисковые запросы

**Статус:** заморожено, не является обязательным условием завершения v6.

- Объединить отчёты «Запросы WB» и «Запросы продавца» в отдельном высоконагруженном аналитическом модуле.
- Расчётный объём — около 250 тысяч строк за один месяц по двум кабинетам; история может вырасти до нескольких миллионов строк.
- Не добавлять сырые запросы в общий полностью загружаемый снимок приложения.
- Для разморозки задачи нужны отдельное хранилище, индексы `дата + кабинет + запрос + товар`, выборка по периоду, предварительные агрегаты, фоновый импорт и виртуализированная таблица.
- Если задача не выполнена в v6, она автоматически переносится в backlog следующей версии без блокировки релиза.
- Разработка начинается только после отдельного решения пользователя о разморозке и выборе локальной либо серверной архитектуры хранения.

## Главная задача — экономика точек входа

Текущая пропорциональная модель распределяет рекламу по всем точкам вместе с заказами. В v6 реклама должна назначаться только тем точкам, где рекламный трафик действительно присутствует.

### Источники и исследование

1. Разобрать имеющиеся отчёты рекламных кампаний и определить доступные ключи кампании, SKU, даты, расходов, кликов и заказов.
2. Сопоставить кампании с товарами и классификацией точек входа.
3. Сформировать подтверждаемое правило рекламной доступности точки, не основанное только на её названии.
4. Определить вес распределения рекламы: фактические рекламные заказы предпочтительнее кликов; показы используются только при отсутствии более близкой к продаже метрики.

### Расчётная модель

- `атрибутированный ДРР точки = рекламные расходы точки / распределённая сумма заказов точки × 100`.
- Рабочая гипотеза корректировки: `расчётная рентабельность точки = базовая рентабельность товара + средний ДРР товара − атрибутированный ДРР точки`.
- Для точки без рекламы атрибутированный ДРР равен нулю, поэтому из неё снимается усреднённая рекламная нагрузка товара.
- `расчётная ЧП точки = распределённая выручка точки × расчётная рентабельность точки / 100`.
- Окончательная формула утверждается после проверки, включены ли рекламные расходы в базовую маржинальность отчёта рентабельности.

### Контроль качества

- Показывать долю рекламных расходов, которую удалось атрибутировать.
- Не распределённые расходы хранить отдельной строкой, а не размазывать по всем точкам.
- Сверять итог заказов, выручки и ЧП по точкам с исходными значениями товара и периода.
- Отмечать расчётные показатели отдельно от фактических.
