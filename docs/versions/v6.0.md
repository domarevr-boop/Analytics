# Analytics MVP v6.0

Статус: **запланирована**. URL: `/Analytics/v6/`.

## Правило перехода

- v6 начинается только после фиксации принятого состояния v4.
- v4 остаётся доступной по своему адресу и не перезаписывается.
- Переносится только рабочий завершённый функционал и явно принятые данные.

## Главная задача: экономика точек входа

### Цель

Перейти от пропорциональной оценки к максимально приближённой экономике источников трафика с учётом фактического присутствия рекламы.

### Исходные данные

- отчёт точек входа;
- воронка продаж;
- рентабельность и чистая прибыль;
- отчёты рекламных кампаний;
- справочник товаров, кабинетов и склеек.

### До реализации

1. Подтвердить, входит ли реклама в маржинальность отчёта рентабельности.
2. Зафиксировать соответствие кампании, артикула, даты и рекламной точки входа.
3. Определить поведение для источников без рекламы и неполных рекламных данных.

### Контроль качества

- сумма заказов по источникам совпадает с исходным периодом воронки;
- рекламные расходы не распределяются на не рекламные источники;
- сумма чистой прибыли после корректировки объяснимо сходится с базовым отчётом;
- расхождения и непокрытые строки отображаются отдельно, а не скрываются.

## Производительность

- диапазонные репозитории и индексы по `product_id + date`;
- серверные или предварительно рассчитанные агрегаты для крупных источников;
- виртуализация длинных таблиц;
- явные лимиты загрузки и диагностика покрытия.
