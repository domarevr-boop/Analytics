# Архив документации

Файлы в этой папке сохранены только для восстановления контекста и не задают текущую архитектуру, задачи или правила проекта.

- `history/` — завершённые версии и старые roadmap.

Старый облачный эксперимент удалён из рабочего дерева. При необходимости его история доступна через Git.

Актуальная навигация находится в [docs/INDEX.md](../INDEX.md), текущее состояние — в [PROJECT_STATE.md](../../PROJECT_STATE.md), незавершённые задачи — в [docs/ROADMAP.md](../ROADMAP.md).
