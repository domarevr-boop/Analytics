# Analytics MVP v2.0

**Статус:** архивный архитектурный этап.

Цель версии — вычислять период A как последние 30 дней от максимальной даты метрик, а период B — как предыдущие 30 дней. Периоды не должны быть отдельным источником истины.

В v3.0 это решение ещё нужно полностью синхронизировать с кодом: `App.tsx` пока сохраняет ручные периоды и показывает `DateRangeFilter`.
